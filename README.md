# Pomodoro Study Timer

A Pomodoro timer web app built with HTML, CSS and JavaScript.

**Live site:** YOUR-VERCEL-URL

## Features
- Large MM:SS countdown with Start, Pause and Reset
- Auto-switches between Focus (25 min) and Break (5 min), with a mode label
- Long break (15 min) after every 4 focus sessions
- Sound when a session ends (different sounds for focus, break and long break)
- Count of focus sessions completed today
- Remaining time shown in the browser tab title
- Settings, session count and music choice saved in localStorage
- Music selector, including a "No music" option

## How to run locally
1. Download or clone this repository.
2. Open `index.html` in a browser. No build step or install is needed.

## Files
- `index.html`: page structure
- `style.css`: styling
- `script.js`: timer logic, sounds, music, storage
